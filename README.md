# 🚆 RailFlow
**Disruption and Platform Conflict Simulator in the Railway Network**

Developed for **VORTEXA 3.0 | Problem Statement P-03**

This simulator allocates trains to platforms and replans the timetables automatically in case of disruptions or platform closure events, providing explanation for all changes.

### ✨ Features
- Conflict-free platform allocation
- Train delays and platform closures
- Disruptions parsing using AI
- Explainable timetables replanning
- Timetable validation
- Impossible schedules processing

### 🛠️ Tech Stack
Python • FastAPI • React • Vite • SQLite/JSON • pytest

### 🤖 AI Tools
ChatGPT for development and debugging support. Optional implementation of Large Language Model to parse natural language disruptions. Scheduling does not require any external API.
